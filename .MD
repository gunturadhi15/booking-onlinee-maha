Saya ingin mengintegrasikan Web Booking ini dengan database Supabase yang terhubung secara terpusat dengan Web Admin. 

Tolong bantu saya melakukan konfigurasi dan penyesuaian kode pada proyek Web Booking ini dengan ketentuan sebagai berikut:

1. Setup Database & Environment Variables:
   - Gunakan Supabase JS Client (`@supabase/supabase-js`).
   - Buat file/modul konfigurasi Supabase client yang membaca variabel lingkungan:
     - `NEXT_PUBLIC_SUPABASE_URL`
     - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - Berikan daftar nama Environment Variable yang harus saya tambahkan ke dashboard Vercel pada proyek Web Booking ini.

2. Skema Tabel Database (`bookings`):
   Pastikan struktur data yang dikirim sesuai dengan skema tabel Supabase `bookings` berikut (atau sesuaikan jika ada kolom tambahan):
   - `id` (uuid, primary key)
   - `customer_name` (text)
   - `customer_phone` (text)
   - `customer_email` (text)
   - `package_name` (text)
   - `tour_date` (date)
   - `total_price` (numeric/integer)
   - `status` (text, default: 'pending', opsi: 'pending', 'paid', 'completed', 'cancelled')
   - `invoice_number` (text)
   - `created_at` (timestamp with time zone)

3. Implementasi Pemesanan & Pembayaran (Booking Flow):
   - Ketika calon pelanggan menyelesaikan formulir pemesanan atau berhasil membuat invoice/melakukan pembayaran, panggil fungsi `insert` ke tabel `bookings` di Supabase.
   - Sertakan penanganan error (error handling) yang memadai serta indikator loading saat proses penyimpanan data berlangsung.
   - Pastikan response sukses mengembalikan detail pesanan/invoice agar dapat ditampilkan kepada pengguna.

Tolong berikan instruksi langkah demi langkah serta perubahan/penambahan kode yang diperlukan.
